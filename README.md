# Sistema de Gestión de Servicios de Taxis (Frontend)

Este repositorio contiene el código fuente del **Frontend** para la plataforma de gestión de transporte **"Taxi Gestión"**.

El proyecto ha sido desarrollado utilizando **Angular v17+** (Standalone Components) cumpliendo con los requisitos del proyecto final de Arquitectura de Software:

> _"Sistema de Gestión de servicio para Taxis"._

---

## 🛠️ Tecnologías y Arquitectura

Este proyecto implementa una **Arquitectura Limpia (Clean Architecture)** y patrones de diseño modernos:

- **Framework:** Angular 17+ (Standalone)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Componentes UI:** PrimeNG (Theming: Amber/Black)
- **Patrones:** Strategy Pattern (Asignación de conductores), Repository Pattern (Servicios).
- **Gestión de Paquetes:** NPM

## 🧩 Instalación y Ejecución

### 1. Clonar el repositorio

```bash
git clone [https://github.com/Edison25G/taxi-gestion-front.git](https://github.com/Edison25G/taxi-gestion-front.git)
cd taxi-gestion-front
2. Instalar dependencias
npm install
```
